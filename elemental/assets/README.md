# 原创视觉素材

使用内置 ImageGen 工具生成后复制进本工程；没有采用 CLI/API 后备模式。保持生成图片的像素和透明通道，运行时使用图集区域与着色器采样。没有复制魔焰铁甲或其他作者的盾牌素材。

| 文件 | 生成提示规格记录 |
|---|---|
| stone-fragments-v2.png | 透明背景16块独立岩甲碎片，手绘灰蓝板岩、斜切边、裂纹、凹坑；宽肩胸片、长条四肢片、中型片、小碎片，4×4排列；不要金属、铆钉、盾牌、符文、霓虹 |
| stone-surface-v2.png | 无缝灰蓝玄武岩甲片表面，大小不一的板块、深色裂缝、手绘斜边、冷色中性光照；不要文字、金属、发光或符号 |
| fire-wall-v3.png | 透明背景4×4连续火墙动画16帧，宽而弯曲的橙金火焰幕、卷动、透空和余烬；不要人物、盾牌、巨大白色火堆底座；各帧保持位置和尺寸，留出透明间隔 |

岩片图集分布不完全等距，extract_regions.py 仅分析 alpha 连通区，生成 stone-fragments-v2.regions.txt，不改图片。TXT 内是 JSON 数组，避免游戏把素材元数据当成 Mod manifest 扫描。

原生火焰噪声、小火和火星通过游戏 res:// 运行时引用，没有分发游戏纹理。图集本身不代表动画已实机验收。
