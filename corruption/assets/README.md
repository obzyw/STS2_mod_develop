# 人物素材与提示规格

模式：内置 ImageGen 编辑，非 CLI/API 后备模式。参考输入为使用者本机原 Mod 的 body.png（位置/画风）和游戏原腐化卡面（人物身份），原图留在本机 artifacts 或原订阅目录，不随本插件发布。

最终图：corruption-warrior-body-v2.png。保留工具生成的透明通道。运行时导入1001×1430的原骨架画布，并对齐原眼睛定位；仅合成头部、头发、兜帽和原胡须占据区域，其他像素取原 Mod 本机图片。

| 生成步骤 | 提示规格 |
|---|---|
| 人物身份修正 | 参考原主体的朝右三分之二视角、透明画布、暗紫/暗红配色、棱角手绘画风及肩部连接位置；把老人换成腐化卡面中的成年铁甲战士。戴暗红铜色面具与刚硬面甲，不露老人鼻口；无胡须、无小胡子、无兜帽。灰白头发从后脑和两侧向画面左后方扬起，嘴下保持深色面甲。不要额外武器/盾牌/肢体/文字/背景 |
| 局部修正 | 只把真实眼睛上方两条金橙色头盔高光改成不发光的暗红铜色斜面，明确仅有一对琥珀眼睛。其余人物、姿势、轮廓、位置、比例、盔甲、头发、透明度保持 |

完整生成图不是整幅覆盖原作者图片。代码只使用其中的身份修正区域，以满足“整体色调、风格、动效时长保持不变”的要求。原手臂、拳头、火焰、衣料条素材均由原 Mod 提供，未另行复制分发。
