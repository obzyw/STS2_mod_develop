# 神格摊掌姿态 0.1.0

**已启用独立 Mod `mods/WatcherDivinityPose`。** 原“美化”模型继续绘制脸、发型、躯干、腿、飘带、原神格法阵及其他附件；仅以新绘制的手臂和衣袖替换原握杖手臂。法杖使用原附件，改为旁侧直立悬浮。不是把整张 AI 人物图盖到原模型上。

| 行为 | 首版结果 |
|---|---|
| 正常/半血神格待机 | 双掌展开，衣袖轻微摆动；保留原角色待机和光影 |
| 出牌、受击、施法、死亡 | 原动作接管，恢复原手臂与法杖；动作结束回到新待机姿态 |
| 退出神格、其他皮肤 | 新手臂退出，原系统继续显示 |
| 残血共用骨架 | 当前保留原动作与原残血外观；未覆盖为新摊掌姿态 |
| 玩法/卡面/已有特效设置 | 不改；重塑仍采用卡面关、人物动作关、特效开 |

最新用户要求是正常游玩可用，不做穷举式防御测试。本次只完成一场原生渲染、无保存测试战斗的三项检查：进入神格显示新动作且原法阵 alpha=1，实际打击造成18伤害后回到新动作，退出神格后恢复。报告和游戏内截图：`artifacts/native-compatibility-20261024-233858/`。画面中的背景眼睛仍正常显示。受击等其他动作使用相同的非 Idle 回退规则，未逐一运行穷尽验证；未验证多人联机。

## 使用与回滚

在工程根目录运行，路径不同时添加 `-GamePath '<游戏目录>'`：

```powershell
./watcher/scripts/Deploy-DivinityPose.ps1
# 先关闭游戏；仅将这个独立 Mod 移出 mods 并归档，不改作者文件：
./watcher/scripts/Deploy-DivinityPose.ps1 -Rollback
```

目前已经安装，不要重复安装。更新自己这份插件时先回滚旧版，再构建部署；作者 YUWatcherForms 更新导致 DLL 哈希变化时，先核对构造入口。正式文件清单及哈希见 `artifacts/divinity-pose-deployment.json`，此次没有替换作者 DLL/PCK/动作覆盖文件。

## 实现与素材

- `Entry.cs`：在作者创建 AnimationPolish 时附加显示节点，复用作者是否正在执行神格动作的判断。
- `DivinityPose.gd`：新手臂使用原人物坐标和原父节点，逐帧恢复/遮蔽旧手臂槽位；头后法阵、原躯干与独立特效不遮蔽。法杖只调整位置和角度，不替换纹理。
- `../assets/divinity/v001/beautified-divinity-body-v002.png`：原型补绘纹理，仅取手臂/衣袖对应 UV 区域；整身其余部分不用于角色替换。生成过程、输入参考和提示词在同目录。
- 新手臂显示只在原神格资源的 Idle 期间生效。作者神格动作正在执行时暂停显示，避免遮住原有攻击动作。没有接管卡牌结算或特效调用。

早期强扭原骨架的试摆不合格，已放弃；早期 C# 素材导出器的退出异常不再扩展排查，其源码归档在 `artifacts/divinity-experiments-20261024/`。后续素材查看使用游戏引擎的原生 GDScript 快速预览，无需每次启动全部订阅 Mod。不要把那些早期失败报告当成最终版验收。
