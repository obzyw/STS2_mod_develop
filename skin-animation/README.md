关闭游戏后可执行 scripts/Rollback-SkinAnimation.ps1 -GamePath <游戏目录>，仅将自有SkinAnimationBridge移入本机artifacts备份，不覆盖作者文件或存档。目前桥只在夹具内临时安装，结束自动撤下。

SilentPose.gd、NecroPose.gd为自有动作代码，角色纹理及骨架始终来自用户订阅的皮肤包，不分发作者素材。猎人保留双脚IK，匕首网格跟随手腕；蛇咬挂接CharacterRig.Find，短函数For会被内联。独立蛇几何沿用作者素材并校准参考腕点。

DefectHeadBridge仅在已适配的冷静头脑/充电绑定范围内提供皮肤表面，不放行其他原版UV/顶点映射。NecroPoseBridge保持ClipPlayer拒绝原版人物网格，以真实皮肤另绘人物，独立法术层继续由作者播放；持续状态和退场仍需检查。

夹具入口 scripts/Test-ElementalVfx.ps1 -Feature SkinAnimation。SkinCards支持角色/牌名筛选，SkinStages默认classic/normal/hurt/critical；classic是普通穿衣模式，独立于破损normal阶段。SkinStageScope只在内存固定设置并核对实际资源路径。无保存夹具结束恢复全部记录、移除探针；禁止与日常游戏同时运行。
