## 在其他电脑恢复效果

1. 安装 Steam 和游戏，订阅并启用清单中的原作者 Mod。当前稳定快照审计游戏版本为 **v0.111.0**；作者更新后可能需要适配，脚本不会强行覆盖未知版本。
2. 下载整个仓库，保留目录结构。关闭游戏即可，**不要放弃正在进行的一局**。
3. 在本工程目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File ./scripts/Install-Portable.ps1 -GamePath 'X:\SteamLibrary\steamapps\common\Slay the Spire 2' -ApplyVisualProfile
```

四个自有插件可直接复制安装，不要求重新编译。首次骨妹兼容生成需要本机 PowerShell 和包内附有许可证的 Mono.Cecil；输入是使用者自己订阅的原始金卡 DLL，输出与备份只写本机 artifacts。没有分发作者 DLL 或游戏文件。

如新电脑也需要显示同步调整，可另运行 `scripts/Set-DisplayStability.ps1`。它匹配当地显示器刷新率，**不要把本机165FPS写死到所有电脑**。当前用户反馈黑闪暂未再出现，根因尚未证实。

## 当前稳定成果

| 角色 | 内容 |
|---|---|
| 亡灵契约师 | 恢复金卡初始化，5张共享牌让位给另两Mod，其余21个类型保留 |
| 静默猎手 | 位移单角色、三方优先级与作者开关修复；刀刃陷阱分阶段、华丽收场过场加谢幕 |
| 储君 | 四能力分域共存、五攻击万象优先，通过作者设置实现 |
| 观者 | 美化人物与卡面、重塑仅特效音效；新神格摊掌及四姿态过渡，原光影保留 |

**当前稳定版仍有一项历史文件修补：骨妹金卡 DLL。游戏本体没有修改。** 储君与观者有作者设置依赖，因此该快照是可迁移开发包，尚非“只订阅一个整合Mod就自动完成全部兼容”的最终产品。复制自己的四个DLL并不能替代原作者的前置订阅。

## 最终产品方向

一个整合Mod，按亡灵契约师、静默猎手、储君、观者分组开关；只有打开相应角色才安装/执行其功能。用运行时兼容替代离线DLL改写与作者配置持久覆盖；原作者Mod作为工坊前置依赖。本轮统一实验已经撤回，不影响已恢复的稳定部署。

## 继续开发

.NET 9 SDK；游戏自带 sts2/GodotSharp/Harmony 作为本地引用。原四个工程接受 `-p:GamePath=<游戏目录>`。ILSpy为可选阅读工具，不必随包安装；所有反编译输出仅保留本地。`artifacts/`、`tools/`、bin/obj不上传；仓库提供的是自有运行文件与精选证据，不包括完整第三方文件、游戏、存档或私人日志。

原始项目说明保存在 [历史README](docs/HISTORY_README.md)。回滚和各组细节见对应docs文档；首次迁移产生的本机备份不要公开上传。尚未发布Steam创意工坊。
